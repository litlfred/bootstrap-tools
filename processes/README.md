# The toolset's Processes

The toolset's own [Processes](https://github.com/litlfred/bootstrap/blob/main/schemas/README.md#process), in bootstrap's diagram vocabulary: `render-kg-to-github-pages.bpmn`, rendering a [Knowledge Graph](https://github.com/litlfred/bootstrap/blob/main/schemas/README.md#knowledge-graph) (or a list of its [Subgraphs](https://github.com/litlfred/bootstrap/blob/main/schemas/README.md#subgraph)) to GitHub Pages at a publication root URL, with each step one of these tools and the push's status and message as its output. The same process for a staging preview and a release; only the root URL differs.

Part of [Bootstrap tools](../README.md) 0.1.0, declared as `bootstrap-tools-processes`, holding `processes`.
